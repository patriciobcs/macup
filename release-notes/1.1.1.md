## Fixed

- The menu bar icon redraws after waking from sleep or changing displays, preventing it from staying cropped until MacUp is relaunched (#22).
- Homebrew-owned Python packages, including its bundled pip, are no longer offered as pip updates. Direct update or removal requests explain that Homebrew manages them, without attempting to overwrite them.
- Scheduled automatic updates run when they are due, without waiting for the next package scan.
- Each package leaves the update list as soon as its upgrade finishes.

Thanks to @PerpetualBeta for the wake/display fix and testing.
