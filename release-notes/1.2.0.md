## New

- **See what’s installed and who manages it.** Open Installations to find desktop apps, command-line tools, language runtimes and global packages. Each entry shows its path, owner and available actions. Run `macup inventory --json` for the same inventory from a terminal.
- **Manage the right copy.** MacUp distinguishes packages installed in different npm prefixes. You can update or remove one copy by selecting it. Scheduled updates and Update All skip inactive copies.
- **Find more apps and tools.** MacUp detects standalone OrbStack, Tailscale, Google Cloud CLI, Claude Code and Devin, and discovers GitHub CLI extensions, .NET and Dart global tools, Nix profiles, and asdf and Volta installs. For desktop apps with a supported release feed, MacUp shows the available version and opens the app or its vendor updater.
- **Update supported runtimes from Installations.** Standalone Node.js updates stay on the installed major version and preserve global npm packages. uv-managed Python updates stay on the installed minor version. MacUp identifies installed Java versions and points to their vendor download pages.

## Fixed

- **App Store updates reflect the version installed on disk.** MacUp checks the app bundle and receipt so stale Spotlight data or a copy on an installer image doesn’t keep an already updated app on the list.
- **Homebrew’s bundled Ruby gems stay with Homebrew.** MacUp skips bundled gems such as `rdoc`, including when a plugin link points into Homebrew’s Cellar. Independently installed gems can still be updated in their own gem directory.
